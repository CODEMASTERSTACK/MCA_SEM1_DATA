## ◈ Module Details

### 1. Python Practical Work

The Python section contains beginner-to-intermediate labs focused on:

- Input and output operations
- Arithmetic and logical computation
- Basic decision-making using conditional statements
- Output formatting and user interaction
- Problem-solving assignments such as total bill calculation and percentage computation

Representative files include:

- `PYTHON- cap776/Practical1.py`
- `PYTHON- cap776/P1Q1.py`
- `PYTHON- cap776/Practical2.py`
- `PYTHON- cap776/Practical3.py`

### 2. C++ Practical Work

The C++ labs emphasize fundamentals of programming such as:

- Variables and input/output
- Conditions and branching
- Loops and iteration
- Recursive function usage
- Event-based arithmetic and number-processing tasks

The practicals are organized under subfolders such as:

- `C++/Practical1/`
- `C++/Practical2/`
- `C++/Practical3/`
- `C++/Practical4/`
- `C++/Practical5/`

### 3. Advanced DBMS Work

The database practicals cover:

- Creating and modifying database tables
- Adding, updating, and querying records
- Using constraints such as primary keys and defaults
- Altering schema and validating operations with SQL commands
- Data retrieval using filtered queries

These are stored in:

- `Advanced_DBMS/practical1.sql`
- `Advanced_DBMS/Practical2.sql`
- `Advanced_DBMS/Practical3.sql`
- `Advanced_DBMS/Practical4.sql`
- `Advanced_DBMS/P1Q1.sql`

### 4. Networking Work

The networking portion includes packet diagram exercises and lab files relevant to network design and communication infrastructure study.

Files include:

- `Networking/P1.pkt`
- `Networking/P2_RingAsBackbone.pkt`

### 5. Academic Resources

The root directory contains course syllabus and reference documents for communication, DBMS, networking, C++, and Python. These files help align the practical implementation work with the study material provided by the curriculum.
